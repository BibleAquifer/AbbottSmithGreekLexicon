# _A Manual Greek Lexicon of the New Testament_ Aquifer Resource

This repository (`AbbottSmithGreekLexicon`) contains Aquifer resource data with resource-level metadata, article-level metadata, and content files in JSON and Markdown formats.

## License

This edition of A Manual Greek Lexicon of the New Testament is licensed with a CC0 license and is in the public domain.

## Structure

The repository is organized by language codes, with each language folder containing subfolders for JSON and Markdown content.

## Documentation

For more information about the Aquifer platform, data, and metadata formats, visit the [Aquifer Documentation repository](https://github.com/BibleAquifer/AbbottSmithGreekLexicon).
